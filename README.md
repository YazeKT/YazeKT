## How I build with AI

**Discover → Specify → Orchestrate → Inspect → Verify → Ship**

1. **Discover the real problem.** Understand the user, constraints, risks, data, and definition of done.
2. **Turn ambiguity into a buildable specification.** Break the work into small, testable product slices.
3. **Direct the right tools and agents.** Use parallel research and implementation where it helps, with clear boundaries and acceptance criteria.
4. **Inspect and correct the output.** Review behaviour, interface quality, failure paths, privacy, licensing, and maintainability.
5. **Test the real workflow.** Combine automated checks with runtime and visual QA; fix errors before calling a feature complete.
6. **Package the result.** Add launchers, documentation, release notes, checksums, and honest status so somebody else can use it.

I have worked across mainstream conversational AI, research assistants, and coding agents. The product name matters less to me than using the right model and tools for the task, maintaining context, and verifying what they produce.
